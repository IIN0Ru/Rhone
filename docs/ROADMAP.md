## Phase 3 — 수직 슬라이스 (Vertical Slice)
30~60분 분량을 **출시 품질**로: 새 아트 + 애니메이션 + **사운드(효과음·BGM)** + 튜토리얼 흐름.
→ 지인/커뮤니티 플레이테스트, "웃긴 사고"가 실제로 터지는지 검증.

## Phase 4 — 콘텐츠 확장
3년 구조와 시간 스킵 활동, 스승·직업 도감(메타 보너스), 동료 수 확대, NPC 호감도·길드·원한 관계, 던전 추가, 엔딩 3종(지배/파괴/평화).

## Phase 5 — 출시 준비
**Steam**
- Steamworks 가입, 앱 등록비(Steam Direct) 납부
- 스토어 페이지 + 트레일러 → 위시리스트 모으기, 데모로 Steam Next Fest 참가
- **AI 생성 콘텐츠 공개 문항** 작성 (PixelLab 사용 → Pre-Generated)
- 업적, 클라우드 저장, Steam Deck 확인

**App Store (iOS)**
- Apple Developer Program 가입(연회비), 빌드에는 Mac + Xcode 또는 클라우드 CI 필요
- 가로 고정, 터치 UI, 노치/세이프 에리어, 앱 심사 가이드라인 확인
- 가격 정책(유료 1회 구매 권장 — 광고/가챠 없음)

**공통**: 영어 현지화(최소), 크레딧/라이선스 화면, 개인정보 처리방침.
