## 6. 경제·시간 🟡
- ✅ 시간: 낮/밤 2구간. 낮 = 상점·의뢰·신전·수련, 밤 = 술집·객잔·뒷골목 이벤트. 던전 다녀오기·큰 활동 → 밤, 숙소에서 자면 다음 날 낮.
- ✅ 난이도: 빠듯하게. 첫 던전 전까지 "동료 2명 + 좋은 숙소" 동시 불가.
- ✅ 파티 최대 4명 (도윤 + 유진 + 고용 2명).
- ✅ **동료/용병 구분**
  | | 동료 | 용병 |
  |---|---|---|
  | 누구 | 유진·연소하·소소·저주받은 기사 | 바르크(이름 있음) + 랜덤 용병 |
  | 합류 | 이벤트·관계 (돈 없음) | 술집·인력소개소에서 **던전 1회당 고용비** |
  | 떠남 | 배신·세력 갈등·호감도 바닥 | 던전에서 돌아오면 계약 끝 (다시 고용 가능) |
  | 연애 | 유진·연소하만 | 없음 |
  | 특이 | 기절 시 호감도 크게 하락 | 기절 시 고용비만 날림. 이름 있는 용병은 호감도 높으면 동료로 전환 |
- ✅ **동료 합류 조건 (데모)**
  - 유진: 처음부터.
  - 소소: 뒷골목에서 지갑 소매치기 → 추격해서 잡으면 선택지. "빵을 사준다" → 합류 / "경비대에 넘긴다" → 합류 안 함, 뒷골목 평판↓.
  - 연소하: 밤에 객잔에서 자객 습격 → 전투에서 함께 막으면 "빚을 졌군" 합류. 자객 = 뒷골목 청부(복선).
  - 저주받은 기사: 던전 2층에서 구출.
  - 바르크(용병): 데모에선 동료 전환까지는 못 가고 "조금만 더" 떡밥까지.
- ✅ 랜덤 용병 그림: 몸 3~4종 × 머리색·옷색 바꾸기, 숨은 특성 랜덤.
- ⬜ 시작 자금, 가격표(용병 고용비·숙소·물약)
## 7. 성장 (직업 4종·레벨·스승) ✅(구조) / 🟡(수치)
### 7-1. 능력치 (힘·민첩·지능·체력) 🟡
| 파생 수치 | 공식 |
|---|---|
| 최대 HP | 20 + 체력×6 |
| 공격력 | 전사·탱커 = 힘×2, 궁수 = 민첩×2, 마법사 = 지능×2.2 (+무기) |
| 방어 | 체력×1 (+방어구) |
| 행동 속도 | 0.8 + 민첩×0.02 (자동 전투에서 다음 행동까지 걸리는 간격의 역수) |
| 치명타 | 민첩×1% (피해 ×1.5) |
| 받는 피해 | max(1, 공격력 − 방어 + 랜덤 −1~+2) |

| 시작 직업 Lv1 | 힘 | 민첩 | 지능 | 체력 | 레벨업 +3 배분(자동) |
|---|---|---|---|---|---|
| 전사 | 7 | 4 | 2 | 6 | 힘2 체력1 |
| 탱커 | 5 | 2 | 2 | 9 | 체력2 힘1 |
| 궁수 | 3 | 8 | 3 | 5 | 민첩2 체력1 |
| 마법사 | 2 | 4 | 8 | 4 | 지능2 민첩1 |
- 도윤만 레벨업 때 **자유 포인트 +1**을 직접 찍는다.
- 레벨 n→n+1 필요 경험치 = 20×n. 데모 기준 1층 끝 Lv2, 2층 끝 Lv3~4, 보스 후 Lv5.

### 7-2. 직업 고유 스킬 (자동 발동) 🟡
| 직업 | 스킬 1 | 스킬 2 |
|---|---|---|
| 전사 | **회전 베기**: 3번째 행동마다 앞쪽 적 2명에게 ×1.2 | — (스승에게서) |
| 탱커 | **도발**: 전투 시작 + 4번째 행동마다, 적 근접 공격이 2회 동안 탱커에게만 | **방패 막기**: HP 30% 이하에서 1회 피해 절반 (전투당 1번) |
| 궁수 | **연사**: 3번째 행동마다 2발 ×0.7 | **저격**: HP가 가장 낮은 적을 노림 (항상) |
| 마법사 | **광역 불꽃**: 4번째 행동마다 모든 적에게 ×0.6 | — (스승에게서) |

### 7-3. 스승 (회차당 1명, 수련 = 3개월 시간 넘기기) 🟡
| 스승 | 위치 | 평판 | 공통 효과 | 직업 연계 스킬 |
|---|---|---|---|---|
| 대장장이 | 자메르 상회 거리 대장간 | 상회 +10 | 대장간 20% 할인 | 전사 **강철 일격**(5번째 행동 ×2.0) / 탱커 **강철 방패**(방어 +30%) / 궁수 **강화 화살**(연사 ×0.9) / 마법사 **마력 지팡이**(광역 불꽃 ×0.8) |
| 사제 | 세렌 신전 | 신전 +10 | 전투 중 1회 **치유의 기도**(파티 HP 30% 회복) | 전사 **신성 베기**(언데드 ×2) / 탱커 **수호**(인접 아군 피해 −20%) / 궁수 **축복 화살**(명중 시 아군 1명 회복 소량) / 마법사 **정화의 빛**(광역 + 저주 해제 → 기사 폭주 확률↓) |
| 거지 노인 | 뒷골목 | 뒷골목 +10 | 정체 랜덤(수련 끝나야 공개) | **진짜 고수**(40%): 직업 스킬 위력 ×1.5 / **가짜**(40%): 아무것도 없음, 3개월 날림 + 노인이 사과 편지와 빵 / **마족**(20%): 강력한 스킬 + 가끔 아군 HP 흡수(사고 유발) |

### 7-4. 무기 선물과 포지션 변경 ✅
- 대상: **동료만** (유진·연소하·소소·기사, 동료가 된 바르크). 용병은 불가.
- 선물한 무기 종류 = 새 포지션: 검·도끼 → 전사 / 방패 → 탱커 / 활·투척 → 궁수 / 지팡이 → 마법사. **4개 포지션 어디로든** 가능.
- 공격력은 새 포지션의 능력치를 따른다(7-1). 능력치가 안 맞으면 처음엔 약함 + 어색한 자리 벌칙 → 같은 포지션으로 싸울수록 **포지션 이해도**↑로 회복(수치는 특성창 기획 때).
- 그림: 무기 오버레이 + 그 포지션의 공격 동작 1개(동료 × 포지션). 동료 4명 × 4포지션 = 공격 동작 최대 16개 → PixelLab 1회씩.
- 무기는 주인공도 쓸 수 있다 → "내가 쓸까, 동료에게 줄까".
