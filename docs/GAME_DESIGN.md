# 게임 기획 — 로운 (Rhone)

> 이 문서는 "무엇을 만드는가"를 다룬다. 왜 그렇게 정했는지는 [DECISIONS.md](DECISIONS.md).

## 1. 컨셉

시골에서 친구 유진과 함께 대도시로 올라온 주인공(남성 고정)이, 제한된 돈으로 동료를 고용하고 던전을 공략하며 도시에서 자리를 잡는 이야기.

핵심 재미는 **"내 마음대로 안 되는 동료"**:
- 숨겨진 특성 — 도망, 활약, 배신, 아군 공격
- 호감도 — 명령 복종 확률, 재고용 수락 여부
- 돈의 딜레마 — 동료를 오래 고용할수록 숙소·식사가 나빠지고, 숙소를 좋게 잡을수록 고용할 돈이 줄어든다

목표 플레이 감각: 첫 판에서 소소가 무섭다고 전투를 거부하고, 저주받은 기사의 특성이 터져 주인공을 쳐서 기절시키는 것 같은 **"웃긴 사고"가 스트리머 클립이 되는 게임.**

## 2. 게임 구조

- **기한**: 정식 3년 (프로토타입 1년=360일). 기한 압박은 약하게, 대신 **시간을 크게 넘기는 활동**으로 리듬을 만든다.
  - 예: 6개월 폐관 수련, 1개월 수련, 3개월 스승 수련, 1개월 무기 제작, 1개월 타지역 물품 공수, 1개월 기도
- **엔딩**: 도시를 지배 / 파괴 / 평화 (프로토타입은 족장 처치 시 평화 엔딩).
- **메타 성장**: 스승 도감·직업 도감 → 메이플 유니온식 영구 보너스.

## 3. 마을 (횡스크롤, 좌우 이동만)

마구간 → 여관 → 잡화점 → 술집 → 객잔 → 뒷골목 → 수련장 → 성문 → 던전 입구.

| 장소 | 기능 |
|---|---|
| 마구간 | 공짜 숙소. 회복 30%, 동료 불만 누적 |
| 여관 | 일반실 12G(회복 60%) / 고급실 30G(완전 회복, 호감도 상승). **침대까지 걸어가서 고른다** |
| 잡화점 | 회복약 10G(전원 HP+35), 선물 8G(호감도+8) |
| 술집 | 바르크 고용, 소문 듣기 |
| 객잔 | 연소하 고용, 소문 듣기 |
| 뒷골목 | 소소 고용, 거지 노인, 동전 줍기, 소매치기 |
| 수련장 | 수련(시간 소모 → 능력치), 스승(거지 노인) |
| 던전 | 성 밖 동쪽 |

처음에는 **숙소 없음** 상태로 시작 → 직접 돌아다니며 숙소를 정한다.

## 4. 고용 · 특성 · 호감도

- 고용 장소: 술집, 객잔, 길가, 던전, (정식) 숲 속, 인력소개소 등.
- 계약: 기간·월급 선택(짧고 비싸게 / 길고 싸게). 고향 친구 유진은 계약 없음.
- **특성**: 고용 시 1개만 공개, 나머지는 `???` — 함께 지내며 드러난다.
- **호감도(0~100)**: 선물, 대화, 던전 클리어, 숙소 질로 변동. 낮으면 명령 불복, 도주, 재계약 거절. 플레이어 레벨이 낮아도 재고용 거절.
- (정식) NPC 호감도, 길드, NPC끼리의 사전 설정된 원한 관계, 1회성 스승 시스템(대장장이·상인·엘프·드워프·사제·은둔고수), 직업 도감.

## 5. 전투 — 대열 + 동료 행동 슬롯 + 사건 개입 (2026-11-17 확정)

영감: 슬롯바운드(3×3 슬롯 + 배치). **가져오는 것**: 3×3 슬롯, 줄 맞추기 보너스, 전투 전 배치. **가져오지 않는 것**: 슬롯으로 유닛 소환(고용 시스템과 충돌), 완전 자동 전투.

```
[전투 전]  대열 정하기 — 횡스크롤 화면에 그대로 보임
           앞 ← 기사 · 유진 · 도윤 · 소소 → 뒤
           앞줄: 맞는 대신 공격력↑ / 뒷줄: 안전, 겁쟁이 도주 확률↓

[매 턴]    슬롯(3×3)을 돌린다 → 칸마다 "동료 + 행동" 심볼
           ┌──────┬──────┬──────┐
           │ ⚔유진 │ ⚔도윤 │ 🏃소소 │
           │ 🛡기사 │ ⚔유진 │ 💰소소 │
           │ 💢기사 │ ⚔도윤 │ ⚔유진 │
           └──────┴──────┴──────┘
           줄 맞춤(같은 행동 3개) → 합동 공격 등 보너스

[사건]     💢·🏃 같은 사고 칸이 나오면 개입 선택
           ⚠ 저주받은 기사가 폭주한다!
           ▶ 말린다 (도윤이 대신 맞음) ▶ 내버려둔다 (적·아군 랜덤) ▶ 금화로 달랜다 (−10G)
```

- **칸 구성 = 동료의 기분.** 동료마다 릴에 넣는 심볼 묶음이 있고, 호감도·숨은 특성·숙소 질·선물이 그 묶음을 바꾼다. 호감도가 낮으면 🏃(도주)·💢(폭주)·💰(손버릇) 칸이 늘어난다.
- 마을에서 하는 모든 행동(숙소, 선물, 대화)이 **다음 전투의 슬롯**으로 이어진다 → 고용 RPG와 전투가 한 줄로 묶임.
- 후퇴 없음(던전 규칙 유지). 도망치는 적은 1턴 뒤 이탈(전리품 손실).

**미정**: 심볼 종류와 수, 릴 구성 규칙, 줄 맞춤 보너스 표, 턴당 결정(돌리기 비용·칸 고정·재돌리기 여부), 적 행동 표시 방식.

## 6. 던전 규칙

- 들어가면 **해당 층을 끝낼 때까지 자동 전진, 중간 탈출 없음.** 층 끝 계단에서 내려갈지/돌아갈지 선택.
- **사망 없음 → 기절**: 
  - 던전 전리품 전부 잃음
  - 10일 뒤 마을(숙소/길바닥)에서 깨어남, 전원 HP 1
  - 동료별 성격에 따른 호감도 하락 (유진 −3 … 연소하 −12)
- 프로토타입: 1층(고블린), 2층 늑대 굴(늑대, 쇠사슬 기사), 3층 족장의 방(고블린 족장).

## 8. 저장

- 자유 저장 3슬롯 (포켓몬식). 던전 안에서만 불가.

## 9. UI (스타듀밸리식)

- 화면 안 HUD: 왼쪽 위 파티 초상화 + 하트(HP), 오른쪽 위 날짜·숙소·골드·남은 기한, 아래 아이템 바(1 회복약, 2 선물, Esc 메뉴).
- 대화: 하단 나무 패널 + 오른쪽 초상화/이름표, 선택지는 위 상자에 ▶ 커서.
- Esc 메뉴: 파티(호감도 하트 5개, 특성 칩, 계약, 보내기) / 일지 / 저장.
- 알림: 파티 초상화 아래 토스트.
- 모바일: 가로 화면 전용, 터치 버튼(◀ ▶ 대화/공격).
