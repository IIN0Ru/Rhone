# 개발 일지

최신이 아래. 새 버전마다 한 항목 추가.

## v1 — 선택지 클릭형 프로토타입
텍스트·버튼으로 하루를 진행. **피드백**: 첫 판에서 소소가 무섭다고 전투 거부, 저주받은 기사가 폭주해 주인공 즉사 → "너무 웃겼다". 하지만 선택지만 보고 고르니 "진짜 게임처럼 느껴지지 않는다" → 횡스크롤로.

## v2 — 메이플식 횡스크롤
좌우 이동, 건물 출입, NPC 말풍선, 필드 턴제 전투.

## v3 — 숙소·던전 규칙
숙소 없음으로 시작, 침대까지 걸어가 방 선택. 던전 자동 전진, 층 끝 계단 선택, 2층 쇠사슬 기사 이벤트.

## v4 — 던전 탈출 금지
"집으로" 버튼 제거. 층을 끝내야 나갈 수 있음.

## v5 — 기절·저장
후퇴 명령 삭제. 사망 → 기절(전리품 전부 잃음, 10일, HP1, 동료별 호감도 하락과 대사). 자유 저장 3슬롯.

## 도트 시안 (A: 0x72 / B: LPC / C: 코드로 찍은 도윤 4종 / D·E: A 캐릭터 + 새 거리)
- A 선호. 코드로 찍은 도윤은 "사람 같지 않다"로 폐기.
- 거리를 A 캐릭터 크기에 맞춰 0.65배로 축소 → ×4 배율 선택.

## v6 — 마을 도트화
새 거리, 0x72 스프라이트, 여관·마구간 실내 도트, 주민 색 변형. 캔버스 960×600.
