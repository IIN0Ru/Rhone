# 크레딧 · 라이선스

## 사용 중인 외부 에셋
| 에셋 | 제작 | 라이선스 | 사용처 |
|---|---|---|---|
| 16x16 DungeonTileset II | 0x72 | **CC0** | 캐릭터·몬스터·UI 아이콘 (임시) |
| 갈무리 (Galmuri11) | quiple | **SIL Open Font License 1.1** | 게임 전체 폰트 — 크레딧 표기 필요, 폰트 단독 판매 금지 |

| 도윤 후보 스프라이트 | PixelLab (AI 생성, 체험판) | PixelLab 약관 — **상업 이용 조건 결제 전 확인 필요** | assets/pixellab/ (시안) |

## 직접 제작
- 거리·실내·던전 배경, 늑대 스프라이트, 색 변형 캐릭터: `tools/pixel/` 스크립트로 제작 (프로젝트 소유)

## 사용하지 않기로 한 것
- LPC 캐릭터(시안 B): CC-BY-SA / GPL 혼합 → 공유 조건 부담으로 미채택
- NoRunNoDungeon 저장소의 대문자 이름 프레임(Townsfolk, Merchant, Wolf 등): **라이선스 불명확 → 사용 금지**

## AI 사용 고지 (Steam 공개용)
- 정식 아트는 PixelLab(AI)으로 생성 예정 → Steam "AI 생성 콘텐츠" 문항에 **Pre-Generated**로 공개.
- 코드 대부분은 AI(Claude)와 함께 작성.
