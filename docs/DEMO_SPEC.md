## 6. 경제·시간 🟡
- ✅ 시간: 낮/밤 2구간. 낮 = 상점·의뢰·신전·수련, 밤 = 술집·객잔·뒷골목 이벤트. 던전 다녀오기·큰 활동 → 밤, 숙소에서 자면 다음 날 낮.
- ✅ 난이도: 빠듯하게. 첫 던전 전까지 "동료 2명 + 좋은 숙소" 동시 불가.
- ✅ 파티 최대 4명 (도윤 + 유진 + 고용 2명).
- ✅ **동료/용병 구분**
  | | 동료 | 용병 |
  |---|---|---|
  | 누구 | 유진·연소하·소소·저주받은 기사 | 바르크(이름 있음) + 랜덤 용병 |
  | 합류 | 이벤트·관계 (돈 없음) | 술집·인력소개소에서 **던전 1회당 고용비** |
  | 떠남 | 배신·세력 갈등·호감도 바닥 | 던전에서 돌아오면 계약 끝 (다시 고용 가능) |
  | 연애 | 유진·연소하만 | 없음 |
  | 특이 | 기절 시 호감도 크게 하락 | 기절 시 고용비만 날림. 이름 있는 용병은 호감도 높으면 동료로 전환 |
- ✅ **동료 합류 조건 (데모)**
  - 유진: 처음부터.
  - 소소: 뒷골목에서 지갑 소매치기 → 추격해서 잡으면 선택지. "빵을 사준다" → 합류 / "경비대에 넘긴다" → 합류 안 함, 뒷골목 평판↓.
  - 연소하: 밤에 객잔에서 자객 습격 → 전투에서 함께 막으면 "빚을 졌군" 합류. 자객 = 뒷골목 청부(복선).
  - 저주받은 기사: 던전 2층에서 구출.
  - 바르크(용병): 데모에선 동료 전환까지는 못 가고 "조금만 더" 떡밥까지.
- ✅ 랜덤 용병 그림: 몸 3~4종 × 머리색·옷색 바꾸기, 숨은 특성 랜덤.
- ⬜ 시작 자금, 가격표(용병 고용비·숙소·물약)
