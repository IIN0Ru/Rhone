## 0. 데모 개요 ✅
- 길이 **30~45분**. 엔진: **TypeScript + Vite + Phaser 4** (Steam=Electron, iOS=Capacitor).
- 흐름: 프롤로그(고향 → 상경) → 로운 도착(중앙 광장) → 숙소·동료 고용·의뢰 → 던전 1~3층 → 고블린 족장 처치 → **봉인 균열 발견, "약 3년" 반전 떡밥** → "정식판에서 계속" 화면.
- 톤: 코미디 + 가끔 찡함.
